# Azərbaycan Dövlət Akademik Opera və Balet Teatrı – Interactive Venue Ticketing

Web & Mobile I project. An interactive seat-selection website for a theatre,
built with HTML, CSS and JavaScript (no backend, no frameworks).

## Venue
- Venue type: theatre / auditorium
- Show: Leyli və Məcnun
- Sections: Orchestra Center, Orchestra Left, Orchestra Right, Mezzanine, Balcony
- Price categories: VIP (120 ₼), Standard (80 ₼), Economy (45 ₼)
- Seats are generated from JavaScript data (`venue-data.js`)

## Files
- `index.html` – page structure
- `style.css` – styling
- `venue-data.js` – venue model (sections, rows, prices)
- `script.js` – seat generation, interaction and cart logic

## How to run
Open `index.html` in a browser.

The venue layout and prices are my own simplified design, inspired by the theatre.
